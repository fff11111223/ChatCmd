# shell_list

## 用途

列出目前由 ChatCMD 管理的持續終端工作階段。

## 基本呼叫

```chatcmd_tool_call
{"id":"call_001","tool":"shell_list","note":"查看目前終端｜唯讀查詢","arguments":{}}
```

## 參數

此工具實際測試可不帶參數。

## 成功結果

實際測試在沒有持續終端時回傳：

```json
{
  "result": []
}
```

`result` 為目前終端工作階段清單；沒有終端時為空陣列。

## 使用建議

- 需要確認目前有哪些持續終端時使用。
- 本工具為唯讀查詢，不會建立或關閉終端。
